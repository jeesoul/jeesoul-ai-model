# 版本 1.1.1 详细说明

发布日期：2025-01-XX

## 概述

1.1.1 是一个**紧急修复版本**，解决了 1.1.0 版本的依赖缺失问题。

## 修复内容

### HttpClient5 依赖缺失问题

#### 问题描述
1.1.0 版本在使用方运行时报错：
```
java.lang.ClassNotFoundException: org.apache.hc.client5.http.config.ConnectionConfig
```

#### 根本原因
- `httpclient5` 依赖的核心库 `httpcore5` 和 `httpcore5-h2` 未在 `dependencies` 中显式声明
- 虽然在 `dependencyManagement` 中管理了版本，但未实际引入到依赖中
- 导致使用方无法通过依赖传递获取这些核心库

#### 修复方案
在 `pom.xml` 的 `dependencies` 中显式添加：
```xml
<dependency>
    <groupId>org.apache.httpcomponents.core5</groupId>
    <artifactId>httpcore5</artifactId>
</dependency>
<dependency>
    <groupId>org.apache.httpcomponents.core5</groupId>
    <artifactId>httpcore5-h2</artifactId>
</dependency>
```

版本由 `dependencyManagement` 统一管理（5.3.6）。

## 升级说明

### 从 1.1.0 升级到 1.1.1

**步骤 1**：修改依赖版本

```xml
<dependency>
    <groupId>com.jeesoul</groupId>
    <artifactId>jeesoul-ai-model</artifactId>
    <version>1.1.1</version>  <!-- 从 1.1.0 改为 1.1.1 -->
</dependency>
```

**步骤 2**：重新编译

```bash
mvn clean compile
```

**完成！** 运行时错误将被解决。

### 从 1.0.x 直接升级到 1.1.1

请参考：[升级到 1.1.0 指南](../migration/upgrade-to-1.1.0.md)

> 注意：指南中的版本号改为 `1.1.1` 即可。

## 影响范围

- **受影响版本**：1.1.0
- **修复版本**：1.1.1
- **影响场景**：所有使用 1.1.0 的项目在运行时都会报错
- **修复方式**：升级到 1.1.1
