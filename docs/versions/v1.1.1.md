# v1.1.1 版本说明

## 版本定位

1.1.1 在现有 ChatGPT 服务上增加 OpenAI 图片识别参数，支持完整图片 URL、图片二进制和已编码的 Base64 图片。
原有纯文本、同步、流式和 Raw 调用方式保持兼容。

## OpenAI 图片输入

OpenAI Chat Completions 使用 `messages[].content` 数组表达文本和图片内容。框架会把统一的 `MessageContent`
转换为 OpenAI 内容片段，其中图片使用 `image_url.url` 字段。

### 完整图片 URL

```java
AiService chatGPT = FactoryModelService.create("chatgpt");

ModelRequestVO request = new ModelRequestVO()
    .setModelName("chatgpt")
    .setModel("gpt-6-astra")
    .setContents(Arrays.asList(
        MessageContent.imageUrl("https://example.com/image.jpg"),
        MessageContent.text("请描述这张图片")
    ));

ModelResponseVO response = chatGPT.httpChat(request);
```

可选的图片详细度会映射为 OpenAI 的 `image_url.detail`：

```java
MessageContent.imageUrl("https://example.com/image.jpg", ImageDetail.HIGH)
```

### 图片二进制

```java
byte[] imageBytes = Files.readAllBytes(Paths.get("image.jpg"));

ModelRequestVO request = new ModelRequestVO()
    .setModelName("chatgpt")
    .setModel("gpt-6-astra")
    .setContents(Arrays.asList(
        MessageContent.imageBytes(imageBytes, "image/jpeg"),
        MessageContent.text("请识别图片中的文字")
    ));
```

`mimeType` 应传入真实图片媒体类型，例如 `image/jpeg`、`image/png` 或 `image/webp`。空数据和空媒体类型会被立即拒绝。

### Base64 图片

```java
MessageContent.imageBase64(base64Data, "image/png")
```

如果 `base64Data` 已经是 `data:image/png;base64,...` 形式，框架会直接使用；普通 Base64 字符串会根据 `mimeType`
包装为 Data URL。历史的 `MessageContent.imageBase64(String)` 仍可使用，未提供媒体类型时默认按 `image/jpeg` 处理。

## 调用方式

同一组 `contents` 参数可用于：

- `httpChat` 同步解析调用
- `streamChat` 和 `streamChatStr` 流式调用
- `httpChatRaw` 和 `streamChatRaw` 原始响应调用

未设置 `contents` 时，ChatGPT 仍使用原来的字符串 `messages[].content`，已有纯文本代码无需修改。

## 配置示例

```yaml
ai:
  chat-gpt:
    api-key: your-openai-api-key
    endpoint: https://api.openai.com/v1/chat/completions
    model: gpt-6-astra
```

模型名称由配置或请求参数传入，框架不会限制具体模型字符串；请以 OpenAI 账户当前可用模型为准。
