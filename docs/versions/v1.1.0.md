# 版本 1.1.0 详细说明

发布日期：2025-01-XX

## 概述

1.1.0 是一个重要的内部重构版本，彻底移除了 Hutool 依赖，自研了 HTTP 封装和 Spring 工具类，并新增了 HTTP 客户端配置支持。**完全向后兼容，对外 API 零变化。**

## 主要改动

### 1. 彻底移除 Hutool 依赖

#### 背景
- 早期版本依赖 `hutool-all`，引入了不必要的依赖传递
- Hutool 的 `SpringUtil` 和 HTTP 工具与项目定位不完全匹配

#### 解决方案
**自研 SpringContextHolder**
- 基于 Spring 原生 `ApplicationContextAware` 实现
- 通过 Spring Boot 自动配置 SPI 注册
- Bean 名为全限定类名，避免与使用方 Bean 冲突
- API 与 Hutool `SpringUtil` 兼容

**自研 HTTP 封装**
- 基于 Apache HttpClient 5.x 实现
- `HttpRequest`/`HttpResponse`/`Method` 仿 Hutool 链式 API
- `HttpClientEngine` 连接池引擎，企业级配置
- API 签名与 Hutool HTTP 完全一致

#### 影响
- **对使用方完全透明**，无需修改任何代码
- 若使用方通过本库传递依赖了 Hutool，需显式引入

### 2. HTTP 客户端配置支持

#### 新增配置
所有 HTTP 客户端参数均可通过 YML 配置：

```yaml
ai:
  http:
    pool:
      max-total: 200              # 连接池最大连接数
      max-per-route: 200          # 每个路由最大连接数
      evict-idle-seconds: 30      # 空闲连接回收阈值（秒）
      time-to-live-seconds: 30    # 连接最长存活时间（秒）
    timeout:
      connect: 5000               # 连接超时（毫秒）
      socket: 10000               # 响应超时（毫秒）
      connection-request: 5000    # 从连接池获取连接的超时（毫秒）
    keep-alive:
      duration: 20000             # 连接保活时间（毫秒）
      enable-retry: false         # 是否启用自动重试
```

#### 特性
- 所有参数可选，不配置时使用默认值
- 支持部分配置，未配置字段使用默认值
- 懒加载机制，首次请求时才初始化
- 降级策略，配置加载失败时使用默认配置

详细配置说明见：[HTTP_CONFIG.md](../HTTP_CONFIG.md)

### 3. 技术改进

#### HttpClientEngine
- 连接池化，最大 200 连接
- Keep-Alive 20 秒，减少握手开销
- 三级超时：连接超时、响应超时、连接池获取超时
- 自动回收空闲连接
- 默认禁用自动重试（适合 LLM 场景）

#### SpringContextHolder
- DCL 双重检查锁定，线程安全
- SPI 自动注册，无需手动配置
- 全限定类名 Bean，避免命名冲突

### 4. 代码质量提升

- pom 显式锁定 Java 8 编译配置
- 版本号规整为语义化版本 `1.1.0`
- `httpcore5` 前置覆盖，避免版本冲突
- 完善 Javadoc 注释，符合中央仓库规范

## 架构设计

### HTTP 封装架构

```
HttpUtils (门面)
    ↓
HttpRequest (链式 API)
    ↓
HttpClientEngine (连接池引擎)
    ↓
Apache HttpClient 5.x
```

### 配置加载流程

```
应用启动
    ↓
AiAutoConfiguration (@EnableConfigurationProperties)
    ↓
HttpClientProperties (Bean 注册)
    ↓
首次 HTTP 请求
    ↓
HttpClientEngine.getProperties() (懒加载)
    ↓
SpringContextHolder.getBean() (获取配置)
    ↓ (成功)
使用 YML 配置构建客户端
    ↓ (失败)
createDefaultProperties() (降级)
    ↓
构建默认配置的客户端
```

## 性能影响

- **连接池复用**：减少连接创建开销

- **懒加载**：不影响应用启动速度
- **单例模式**：全局共享一个客户端实例
