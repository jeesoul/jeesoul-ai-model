# 1.1.0 版本依赖问题解决方案

## ⚠️ 问题说明

1.1.0 版本存在依赖缺失问题，运行时会报错：
```
java.lang.ClassNotFoundException: org.apache.hc.client5.http.config.ConnectionConfig
```

## 🔧 临时解决方案（适用于 1.1.0）

如果你已经使用了 1.1.0 版本，请在你的项目 `pom.xml` 中添加以下依赖：

```xml
<dependencies>
    <!-- 你的 jeesoul-ai-model 依赖 -->
    <dependency>
        <groupId>com.jeesoul</groupId>
        <artifactId>jeesoul-ai-model</artifactId>
        <version>1.1.0</version>
    </dependency>
    
    <!-- 补充缺失的 HttpClient5 核心依赖 -->
    <dependency>
        <groupId>org.apache.httpcomponents.core5</groupId>
        <artifactId>httpcore5</artifactId>
        <version>5.1.5</version>
    </dependency>
    <dependency>
        <groupId>org.apache.httpcomponents.core5</groupId>
        <artifactId>httpcore5-h2</artifactId>
        <version>5.1.5</version>
    </dependency>
</dependencies>
```

### 版本说明
- 如果你使用 **Spring Boot 2.6.x/2.7.x**，使用 `httpcore5: 5.1.5`
- 如果你使用 **Spring Boot 3.x**，使用 `httpcore5: 5.2.x`
- 如果不使用 Spring Boot，使用 `httpcore5: 5.1.5`

## ✅ 推荐方案

**直接升级到 1.1.1 版本**（已修复所有依赖问题）

```xml
<dependency>
    <groupId>com.jeesoul</groupId>
    <artifactId>jeesoul-ai-model</artifactId>
    <version>1.1.1</version>
</dependency>
```

1.1.1 版本已经显式声明了所有依赖，无需额外配置。

## 📋 验证

添加依赖后，重新编译并启动应用：
```bash
mvn clean compile
mvn spring-boot:run
```

确认：
- ✅ 应用启动成功
- ✅ AI 模型调用正常
- ✅ 无 ClassNotFoundException 错误

## 💡 为什么会出现这个问题？

1.1.0 版本的 `pom.xml` 中缺少了 `httpcore5` 和 `httpcore5-h2` 的显式声明，导致这些依赖没有传递到使用方项目中。
