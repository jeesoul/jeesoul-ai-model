# 版本 1.1.0-beta2 详细说明

发布日期：2025-01-XX

## 概述

1.1.0-beta2 是 1.1.0-beta 的紧急重发版本。

**1.1.0-beta 的问题**：虽然本地构建时 pom.xml 正确声明了依赖，但发布到中央仓库时遗漏了依赖声明修复，导致用户下载后运行时仍报 `ClassNotFoundException`。

1.1.0-beta2 是同样的代码和 pom，重新发布并验证中央仓库上的版本确实包含了正确的依赖声明。待该版本在实际项目中验证稳定后，将以相同内容发布 1.1.1 正式版。

## 修复内容

### HttpClient5 依赖缺失问题

#### 问题描述
1.1.0 版本在使用方运行时报错：
```
java.lang.ClassNotFoundException: org.apache.hc.client5.http.config.ConnectionConfig
java.lang.ClassNotFoundException: org.apache.hc.core5.http.HttpEntity
java.lang.ClassNotFoundException: org.apache.hc.core5.io.ModalCloseable
```

#### 根本原因
1. 1.1.0 把 `httpcore5` 和 `httpcore5-h2` 写在了 `<dependencyManagement>` 中。该节点只管版本、不引入依赖，因此这两个包不会作为传递依赖交付给使用方
2. `httpclient5` 锁的是 5.5.1，需要配套 `httpcore5` 5.3.x；而使用方多为 Spring Boot 2.7.x，其 BOM 把 `httpcore5` 管在 5.1.x，版本线对不上
3. 作为通用组件，依赖了自身 Spring Boot BOM 管理版本，不够独立

#### 修复方案
**显式声明所有 HttpClient5 依赖，确保通用组件的独立性：**

```xml
<dependency>
    <groupId>org.apache.httpcomponents.client5</groupId>
    <artifactId>httpclient5</artifactId>
    <version>5.2.3</version>
</dependency>
<dependency>
    <groupId>org.apache.httpcomponents.core5</groupId>
    <artifactId>httpcore5</artifactId>
    <version>5.1.5</version>
</dependency>
<dependency>
    <groupId>org.apache.httpcomponents.core5</groupId>
    <artifactId>httpcore5-h2</artifactId>
    <version>5.1.5</version>
</dependency>
```

**版本选择理由：**
- `httpclient5 5.2.3`：稳定版本，广泛支持
- `httpcore5 5.1.5`：与 httpclient5 5.2.x 完全兼容
- 兼容 Spring Boot 2.6.x/2.7.x/3.x
- 不依赖使用方的 BOM，版本可预测

## 通用组件设计原则

1.1.0-beta 版本遵循通用组件的最佳实践：

### 1. 独立性
- 所有依赖显式声明版本
- 不依赖使用方的依赖管理
- 不假设使用方的技术栈

### 2. 可预测性
- 依赖版本明确，不会被覆盖
- 行为一致，不受环境影响

### 3. 兼容性
- 选择稳定且广泛支持的版本
- 兼容主流 Spring Boot 版本
- 支持非 Spring Boot 项目

## 升级说明

### 从 1.1.0-beta 升级到 1.1.0-beta2

**步骤 1**：修改依赖版本

```xml
<dependency>
    <groupId>com.jeesoul</groupId>
    <artifactId>jeesoul-ai-model</artifactId>
    <version>1.1.0-beta2</version>  <!-- 从 1.1.0-beta 改为 1.1.0-beta2 -->
</dependency>
```

**步骤 2**：强制更新并重新编译

```bash
mvn clean install -U
```

**完成！** 运行时错误将被解决。

### 从 1.1.0 升级到 1.1.0-beta2

**步骤 1**：修改依赖版本

```xml
<dependency>
    <groupId>com.jeesoul</groupId>
    <artifactId>jeesoul-ai-model</artifactId>
    <version>1.1.0-beta2</version>  <!-- 从 1.1.0 改为 1.1.0-beta2 -->
</dependency>
```

**步骤 2**：重新编译

```bash
mvn clean compile
```

**完成！** 运行时错误将被解决。

### 从 1.0.x 直接升级到 1.1.0-beta

请参考：[升级到 1.1.0 指南](../migration/upgrade-to-1.1.0.md)

## 影响范围

- **受影响版本**：1.1.0
- **修复版本**：1.1.0-beta

- **修复方式**：升级到 1.1.0-beta；不便升级的项目可按 [v1.1.0 补丁方案](v1.1.0-hotfix.md) 在自身 pom 补三个依赖（已实测验证可用）
